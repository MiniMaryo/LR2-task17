**1. Создать консольное приложение, в котором описаны классы, реализующие
иерархию наследования в соответствии с вариантом задания.<p>
2. Базовый класс должен иметь как минимум два поля различных типов и
метод.<p>**
**3. Производные классы могут иметь**
- дополнительные поля,  
- реализовать свои методы  
- переопределять методы базового класса.  
<p></p>

**4. В функции Main() класса Program**
- создать объекты (экземпляры) классов  
- сохранить их в коллекции (или массиве).  
- вызвать в цикле на выполнение переопределенные методов
  объектов.  

Базовый класс: Точка  
- свойства:  
  - координата X,  
  - координата Y;  
- методы:  
  - Показать() – выводит данные класса,  
  - Нарисовать() – вывод «рисуем точку»
  
Производный класс: Цветная точка  
- свойство:  
  - цвет;  
- методы:  
  - Показать() – выводит данные объекта на экран;  
  - Нарисовать() – вывод «Рисуем {цвет} точку»;  
  
Производный класс: Трех мерная точка  
- свойство:  
  - координата Z;
- методы:  
  - Показать();  
  - Нарисовать() – выводит фразу «Координаты точки {X}, {Y}, {Z}»
